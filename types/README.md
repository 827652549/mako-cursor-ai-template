# Types

根目录类型定义，用于存放框架相关的类型定义。

## 目录说明

此目录用于存放与框架或项目基础设施相关的类型定义，与 `src/types/` 目录的业务类型区分。

## 文件说明

- `routes.d.ts` - 路由相关的类型定义
- `validator.ts` - 验证器相关的类型定义

## 与 src/types/ 的区别

- `types/` - 框架相关类型（路由、验证器等）
- `src/types/` - 业务相关类型（API 响应、业务实体等）

## 注意事项

- 此目录的类型定义通常是全局的或框架层面的
- 业务相关的类型应该放在 `src/types/` 目录
- 类型定义应该使用 TypeScript 严格模式
