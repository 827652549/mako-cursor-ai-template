# Public

静态资源目录，存放所有不需要构建处理的静态文件。

## 目录说明

此目录下的文件会直接复制到构建输出的根目录，可以通过 `/filename` 路径直接访问。

## 文件类型

- 图片文件（`.svg`, `.png`, `.jpg`, `.webp` 等）
- 字体文件（`.woff`, `.woff2`, `.ttf` 等）
- 其他静态资源（`.json`, `.xml` 等）

## 使用规范

- 使用绝对路径引用资源，如 `/next.svg`
- 图片文件建议使用优化的格式（WebP、AVIF）
- 大文件考虑使用 CDN 而非放在此目录
- 文件名使用 kebab-case 命名

## 注意事项

- 此目录的文件不会被构建工具处理
- 文件路径大小写敏感
- 避免在此目录放置大量文件，影响构建速度
